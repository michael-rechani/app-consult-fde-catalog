# Health check

## What it does

Checks an Azure environment against a set of health and reliability checks and lists what it finds.

## When to use it

- **Scenario:** A team wants to know the current state of an existing Azure workload, for example at the start of an engagement or before a major change.
- **What you get:** A list of findings the team can review and prioritise.

## Prerequisites

- **Access:** Read access to the subscriptions in scope.
- **Tooling:** Listed in the resource repository.
- **Azure services:** The services in the workload being checked.

## Limits

- It reports findings. It doesn't change anything in the environment.
